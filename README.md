# Garden App Robust

A full-featured, immersive gardening and horticulture application built as an evolution of a foundational task assignment from an AI engineering module. 

## 🌐 Live Demo
Check out the live application hosted on GitHub Pages:
[https://arianmalayery-studio.github.io/garden-app-robust/](https://arianmalayery-studio.github.io/garden-app-robust/)

---

## 🌱 Motivation
What started as a structured coding and version control task assignment within an AI engineering module evolved into a passion project: a fully realized, feature-rich application for gardening and botanical enthusiasts. This project expands significantly upon the core codebase originally established in [garden-app](https://github.com/arianmalayery-studio/garden-app), transforming simple scripts and hardcoded advice into a dynamic, polished, and robust user experience.

---

## ✨ Features
- **Seasonal & Monthly Gardening Advice:** Tailored tips and guidance based on the current season and month to help green thumbs optimize planting, maintenance, and harvesting schedules.
- **Comprehensive Plant Directory:** Detailed profiles featuring high-resolution imagery, sensorial breakdowns, care requirements, and growth stages.
- **Interactive Horticultural Tools:** Dynamic layouts designed to help users track, plan, and learn about diverse flora.
- **Robust Architecture:** Clean structure, enhanced documentation, and modular logic scaled up from the original module task.
